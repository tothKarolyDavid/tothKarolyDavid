### [Habitinator](https://github.com/tothKarolyDavid/Habitinator)
A full-stack **.NET 11** productivity suite shipped as **Blazor Web** and **MAUI Hybrid** apps. Offline-first **SQLite** sync keeps users productive without a connection, backed by a **PostgreSQL** server with idempotency-backed **REST APIs** that guarantee reliable data delivery. Orchestrated with **.NET Aspire** for a production-grade local stack and hardened by an end-to-end test suite using **Playwright** and **Testcontainers**.
